# Mental Models and Heuristics

Toolkit: inversion, second-order thinking, opportunity cost, expected value, base rates, Occam's razor, falsifiability, signal/noise, leverage points, Chesterton's fence, map-vs-territory.

Primary sources/leads: Kahneman and Tversky on heuristics/biases; Donella Meadows on leverage points; Popper on falsifiability; Chesterton's fence as a conservative-change heuristic.

Quick table:
- Inversion: ask what guarantees failure. Backfires if it only produces fear.
- Occam: prefer simpler explanation. Backfires when systems are genuinely complex.
- Base rates: anchor in prior outcomes. Backfires when current case is structurally different.
- Chesterton: understand before removing. Backfires when used to protect broken systems forever.

Invoke this when: a compact lens can sharpen judgment. This misleads when: model becomes slogan.
