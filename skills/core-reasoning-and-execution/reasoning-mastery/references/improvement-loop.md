# Improvement Loop for Reasoning Mastery

After every hard task:
1. Identify problem shape and selected playbook.
2. Compare predicted vs actual outcome.
3. Log reasoning failures in ERRORS.md only if reusable.
4. Patch references/templates when a better move is discovered.
5. Do not save transient task progress as memory.

Usage image: use this after difficult, ambiguous, or failed work.
