# Persistence, Creativity, and Solution Search

Stuck moves: change representation, draw the system, invert, shrink the problem, solve a toy version, relax constraints, seek an analogy, split differently, change tool, or stop with proof.

Primary sources/leads: Polya's look-for-related-problem advice; creative problem-solving literature; mathematical problem transformation.

Decision rule:
- Keep pushing if a viable untested path remains.
- Switch if retries are repeating the same failed hypothesis.
- Stop if constraints logically prevent solution or required information is unavailable.

Worked example: If a network provider fails, switch to local deterministic validation. If exact external state is unknowable, state that and offer a bounded estimate.

Invoke this when: repeated attempts fail. This misleads when: creativity becomes random thrashing.
