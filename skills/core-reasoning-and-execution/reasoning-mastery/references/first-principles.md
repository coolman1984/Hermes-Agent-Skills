# First-Principles Reasoning

Core move: strip the problem to fundamental truths, constraints, and causal mechanisms; rebuild from there instead of copying analogy. For Mohamed's Arabic thinking style, this is the تأصيل habit: why does this exist, what decision does it serve, what is the original cause, and what follows from it?

Primary sources/leads: Aristotle's first principles tradition; Descartes' methodic doubt; Feynman-style derivation; Elon Musk's engineering framing is a modern example but not a primary theory source.

Procedure:
1. State the goal and decision served.
2. List assumptions.
3. Mark each as fixed constraint, empirical fact, convention, or preference.
4. Remove conventions and rebuild the simplest route from fixed constraints.
5. Compare against analogy-based solution.

Worked example: “We need a complex crawler.” First principles may reveal the fixed need is fresh data with provenance; if an official API gives it, crawler complexity is convention, not necessity.

Invoke this when: inherited assumptions dominate. This misleads when: you ignore accumulated domain wisdom or real operational constraints.
