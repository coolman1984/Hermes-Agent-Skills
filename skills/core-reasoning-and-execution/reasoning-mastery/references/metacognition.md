# Metacognition and Continuous Learning

Think about the thinking: which mode did the problem need, where did confidence exceed evidence, what prediction was wrong, what prevention rule should be saved?

Primary sources/leads: deliberate practice literature; calibration and forecasting practice; Argyris double-loop learning.

Procedure after hard task:
1. What problem shape was it?
2. Which playbook helped?
3. Which assumption failed?
4. What evidence caught it?
5. What prevention rule belongs in ERRORS.md?
6. Does a template/playbook need patching?

Invoke this when: after any hard or repeated task. This misleads when: you log noisy one-off details into durable memory.
