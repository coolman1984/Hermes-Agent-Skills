# Decomposition and Structured Problem-Solving

Use MECE splits, issue trees, hypothesis-driven analysis, working backward, reduction, constraint relaxation, and Polya's four steps: understand, plan, execute, look back.

Primary source: George Polya, How to Solve It. Management-consulting issue trees and scientific hypothesis testing are later operational forms.

Procedure:
1. Define final output.
2. Split into independent dimensions.
3. For each branch, state hypothesis and falsifying evidence.
4. Solve easier relaxed version if stuck.
5. Recompose and check gaps/overlaps.

Worked example: “Build a report factory” decomposes into acquisition, extraction, validation, database, report rendering, delivery, governance.

Invoke this when: the problem has many moving parts. This misleads when: splits are artificial or dependencies are hidden.
