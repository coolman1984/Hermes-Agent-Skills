# Execution Control

Track leading indicators and blockers, not just percent complete. Use checkpoints, acceptance tests, and stop/switch criteria. Keep plans living but controlled: change because evidence changed, not because focus drifted.

Cadence: daily for active build, weekly for project review, milestone review for major gates.

Invoke this when: a plan is being executed. Misleads when: status updates replace real verification.

Sources/leads: agile review cycles, earned value concepts, operational project control.
