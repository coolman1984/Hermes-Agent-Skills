# Decomposition and Sequencing

Break goal into phases, milestones, tasks, and steps. Every task needs input, output, acceptance criterion, dependency, and owner. Prefer vertical slices when learning matters; use horizontal layers only when foundation risk dominates.

Pattern: phase → milestone → task → acceptance test.

Worked example: Excel pipeline first slice is one folder → one raw table → one validation → one query → one report, before dashboards or scheduling.

Invoke this when: work spans days/weeks or multiple systems. Misleads when: work breakdown becomes bureaucracy.

Sources/leads: work breakdown structure, agile vertical slicing, critical path method.
