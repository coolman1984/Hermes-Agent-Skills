# Resources and Leads

| Area | Source / lead | Use |
|---|---|---|
| Project management | PMI PMBOK | scope, schedule, risk, stakeholders |
| Risk | ISO 31000 concepts, Gary Klein pre-mortem | concrete risk thinking |
| Forecasting | Tetlock, Good Judgment Project | calibration, base rates, updates |
| Planning fallacy | Kahneman and Tversky | outside view and optimism bias |
| Estimation | PERT, reference class forecasting | ranges, assumptions |
| Product planning | OKRs, working backwards, RICE | outcomes and prioritization |
| Execution | agile checkpoints, milestone reviews | learning cadence |

Top traps: activity not outcome, single date estimates, no checkpoint, vague risks, no owner, hidden assumptions, building dependencies first forever, no kill criteria, over-planning before evidence, no predicted-vs-actual loop.

Usage image: use this when expanding the skill with deeper primary-source research.
