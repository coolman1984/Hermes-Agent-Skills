# Improvement Loop

After every multi-step effort:
1. Compare forecast vs actual.
2. Record estimate miss, risk miss, sequencing miss, or priority miss.
3. Update ERRORS.md only with reusable prevention rules.
4. Update templates if the missing field caused the miss.
5. Keep plan changes tied to evidence, not mood or novelty.

Usage image: use after milestones, failed plans, or completed projects.
