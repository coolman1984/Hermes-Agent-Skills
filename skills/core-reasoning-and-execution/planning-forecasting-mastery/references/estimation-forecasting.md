# Estimation and Forecasting

Use ranges, not single-point certainty. Combine inside view (task details) with outside view (reference class/base rate). Track confidence and assumptions. Use three-point estimates: optimistic, likely, pessimistic.

Formula: expected rough duration = weighted range, but report as range with confidence, not false exactness.

Worked example: “build first working Excel pipeline” might be 1–2 days with clean sample files, 3–5 days with messy unknown formats.

Invoke this when: user asks how long, how costly, or how likely. Misleads when: probabilities are invented with no reference class.

Sources/leads: Kahneman/Tversky planning fallacy, Tetlock superforecasting, PERT estimation.
