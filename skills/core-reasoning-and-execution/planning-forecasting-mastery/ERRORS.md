# Planning and Forecasting Error Log

## 2026-07-08 — Treating a plan as a promise
- Predicted: a fixed plan would survive execution unchanged.
- Happened: new information changed sequence and scope.
- Why missed: plan had no uncertainty range or checkpoint.
- Prevention rule: every non-trivial plan must state assumptions, range, and next review point.

## 2026-07-08 — Vague risk language
- Predicted: “it may fail” was enough risk handling.
- Happened: failure mode was too vague to mitigate.
- Why missed: risk did not include trigger, impact, and countermeasure.
- Prevention rule: write risk as concrete event + trigger + impact + mitigation + owner.

## 2026-07-08 — Over-planning before first evidence
- Predicted: more detail would reduce risk.
- Happened: detail became waste because early assumptions were untested.
- Why missed: plan skipped smallest learning slice.
- Prevention rule: first plan should buy evidence before it buys scale.
