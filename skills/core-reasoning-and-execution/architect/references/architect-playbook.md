# Architect Playbook

## Planning checklist
- Define the real problem.
- List constraints and unknowns.
- Identify what must be decided now versus later.
- Prefer the simplest solution that meets the requirement.
- Call out tradeoffs explicitly.
- Turn the design into clear implementation steps.

## Approval standard
A design is usable when:
- the goal is unambiguous
- the major risks are named
- the implementation path is concrete
- the user can hand it to a builder or developer directly
