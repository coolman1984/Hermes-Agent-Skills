# Planning Mastery Error Log

## 2026-07-08 — Confusing estimate with commitment
- Predicted: estimate range would be treated as planning input.
- Actual: user/stakeholder may hear it as a promise.
- Why missed: plan did not label estimate vs commitment.
- Prevention rule: every estimate must say what scope/quality/risk assumptions it depends on and whether it is a commitment.

## 2026-07-08 — Planning fallacy through inside-view optimism
- Predicted: clean path based on current task list.
- Actual: hidden dependencies and messy inputs often extend timeline.
- Why missed: no reference class or worst-case range.
- Prevention rule: compare to similar past work and include pessimistic case plus buffer.

## 2026-07-08 — Risk without trigger cannot be managed
- Predicted: named risk would be enough.
- Actual: team did not know when to act.
- Why missed: risk omitted early-warning signal.
- Prevention rule: every risk needs trigger signal, mitigation, contingency, and owner.

## 2026-07-08 — Roadmap without phase gates drifts
- Predicted: sequence alone would guide execution.
- Actual: work continued despite weak evidence.
- Why missed: no entry/exit criteria.
- Prevention rule: each phase needs measurable exit criteria and a branch/stop decision.

## 2026-07-08 — Simulated phase review: header structure miss
- Predicted: sample files shared one header row.
- Actual: one file had title row plus merged header.
- Why missed: inspection only checked first sheet visually.
- Prevention rule: detect header candidates per sheet and record confidence before extraction.
