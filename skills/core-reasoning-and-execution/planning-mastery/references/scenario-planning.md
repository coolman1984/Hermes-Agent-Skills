# Scenario Planning

Prepare best / likely / worst cases, with triggers and responses. Use decision trees for branching futures. Sensitivity thinking asks: which assumption, if wrong, breaks the plan hardest?

Worked example: hard 2-week deadline. Best: 5 uniform files and full report. Likely: 3 files and 3 queries. Worst: only validated raw load and reconciliation memo. Dangerous assumption: source format is stable.

Use when: deadline or external uncertainty dominates. Over-engineers when: uncertainty is low and action is reversible.
