# Estimation

Estimate honestly using reference-class forecasting, three-point estimates, buffers, and explicit planning fallacy warning. Distinguish estimate from commitment.

Formula: optimistic / likely / pessimistic. Report range and confidence. Re-estimate when new information arrives.

Worked example: first Excel-to-database report: 1 day if files are uniform; 2–3 days likely; 5+ days if headers/sheets vary or reconciliation fails.

Use when: time, cost, or effort matters. Over-engineers when: next step is a 15-minute experiment.
