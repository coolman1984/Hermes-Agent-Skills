# Decomposition

Break goal into phases → milestones → tasks → steps. Every unit needs owner, input, output, acceptance criterion, dependency, and estimate. Use vertical slicing to get end-to-end learning early; use horizontal layers only when shared foundations are the main risk.

Worked example: Excel report pipeline: inspect samples → raw load → validation → clean table → 3 queries → Excel report → schedule.

Use when: work needs more than one sitting or touches multiple systems. Over-engineers when: a single reversible action can answer the question.
