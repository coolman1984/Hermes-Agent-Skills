# Risk Forecasting

Run premortem: imagine the project failed and work backward. Build risk register: risk, probability × impact, trigger, mitigation, contingency, owner. Distinguish mitigation from contingency.

Watch for single points of failure, second-order consequences, known-unknowns, and unknown-unknowns. Reduce known-unknowns by research; absorb unknown-unknowns with buffer and adaptability.

Worked example: risk: month-end export changes headers. Trigger: required column missing. Mitigation: schema gate. Contingency: manual mapping review.

Use when: failure costs money, trust, or time. Over-engineers when: no meaningful downside exists.
