# Prioritization

Use value/effort, MoSCoW, weighted scoring, opportunity cost, expected value, reversibility, leverage, de-risking, and learning. Decide what NOT to do.

Sequencing by leverage: what unblocks the most, de-risks the most, or teaches the most earliest.

Worked example: build validation before dashboard polish because wrong reports destroy trust.

Use when: backlog is crowded. Over-engineers when: one task clearly dominates or a deadline dictates order.
