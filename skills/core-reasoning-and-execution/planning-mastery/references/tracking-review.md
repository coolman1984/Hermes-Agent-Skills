# Tracking and Review

Track status, blockers, leading indicators, and expected vs actual. Re-plan when reality diverges without abandoning the goal. Retrospective turns planning misses into prevention rules.

Calibration: track whether likely estimates actually happen as often as claimed.

Worked example: after phase 1, expected 3 uniform files; actual 1 file had two header rows; prevention: inspection must classify header row per sheet.

Use when: plan is active or phase completed. Over-engineers when: plan is exploratory and lasts less than a day.
