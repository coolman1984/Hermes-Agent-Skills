# Roadmap and Sequencing

Map dependencies, critical path, parallelizable work, and bottleneck. Use Now / Next / Later for long horizons. Add phase gates with entry and exit criteria.

Critical path: the dependency chain that sets the minimum timeline. Theory of constraints: improve the true bottleneck, not random busy areas.

Worked example: reporting pipeline critical path is sample inspection → schema decision → raw load → validation → clean model → report. Styling can run later; validation cannot.

Use when: timeline, dependencies, or long-horizon roadmap matters. Over-engineers when: order is obvious and low-risk.
