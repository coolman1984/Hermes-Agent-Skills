# Improvement Loop

After a plan runs:
1. Compare predicted vs actual.
2. Score estimates: optimistic, likely, pessimistic, actual.
3. Add missed risks to `risk-forecasting.md` if reusable.
4. Add blown-estimate patterns to `ERRORS.md`.
5. Adjust reference class for future estimates.
6. Patch templates when a missing field caused the miss.

Usage image: use at every phase review and after every missed estimate.
