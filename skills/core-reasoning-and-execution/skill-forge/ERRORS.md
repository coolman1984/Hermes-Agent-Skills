## 2026-07-07 — Field-mastery request can be too large for one pass
- Symptom: A broad mastery protocol asks for senior-level research, scripts, validation, and packaging in one run.
- Root cause: The protocol is intentionally ambitious and can exceed a single context window.
- Fix: Build a tested high-leverage skill package first, record source map and validation, then mark the single next research frontier.
- Prevention rule: Never fake exhaustive mastery; ship a validated foundation and declare the next research edge.
