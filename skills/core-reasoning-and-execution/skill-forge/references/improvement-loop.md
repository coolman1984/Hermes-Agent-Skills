# Skill Improvement Loop

Every time any skill is used on a real task, before finishing ask:

1. Did I hit a gap the skill did not cover?
   - Add it to the relevant reference or SKILL router.
2. Did I make an error?
   - Log it in `ERRORS.md` as symptom → root cause → fix → prevention.
3. Did I learn a better way?
   - Replace the old way and note why.

This makes skills self-sharpening with use.

Rules:
- Do not save temporary task progress as a skill lesson.
- Save only reusable procedures, pitfalls, and verification patterns.
- If a skill is wrong, patch it immediately before final response.
