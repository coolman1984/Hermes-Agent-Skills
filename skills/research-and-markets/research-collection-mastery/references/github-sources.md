# GitHub and Code Sources

Use GitHub REST/GraphQL APIs with tokens when available, respect rate limits, paginate Link headers, and record query. For bulk history use GH Archive. Clone only when code content is needed.

Sources: GitHub REST https://docs.github.com/en/rest ; GraphQL https://docs.github.com/en/graphql ; GH Archive https://www.gharchive.org/

When to use: repos, issues, releases, commits, search. When it fails: rate limits, private repos, code search limitations.

Usage image: choose authorized source, collect raw, manifest it, then hand off.
