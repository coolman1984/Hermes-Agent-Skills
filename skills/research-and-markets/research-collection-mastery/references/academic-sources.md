# Academic Sources

Use authorized APIs/dumps first: arXiv API, Semantic Scholar API, OpenAlex, Crossref, PubMed/Entrez, CORE, Unpaywall for legal OA PDFs, DOI resolution. Google Scholar has no official API; prefer these sources.

Sources: arXiv API https://info.arxiv.org/help/api/ ; OpenAlex https://docs.openalex.org/ ; Crossref https://api.crossref.org/ ; PubMed Entrez https://www.ncbi.nlm.nih.gov/books/NBK25501/ ; Unpaywall https://unpaywall.org/products/api

When to use: paper metadata, citation graphs, legal PDFs. When it fails: closed full text; use metadata and legal OA links only.

Usage image: choose authorized source, collect raw, manifest it, then hand off.
