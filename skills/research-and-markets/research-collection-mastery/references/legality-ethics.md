# Legality and Ethics

Checklist: legal basis, terms, robots, license, copyright, privacy, auth scope, rate limits, data minimization, retention, and whether the user has authority. Stop when source forbids automated access.

Source: Python robotparser https://docs.python.org/3/library/urllib.robotparser.html

When to use: every source. When it fails: no lawful route; ask for export/API/permission.

Usage image: choose authorized source, collect raw, manifest it, then hand off.
