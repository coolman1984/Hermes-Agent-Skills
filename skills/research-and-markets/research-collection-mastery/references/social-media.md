# Social Media, Forums, and News

Official APIs and real limits first: Reddit API/PRAW, YouTube Data API, Mastodon API, Telegram Bot/User APIs, X/Twitter API where access exists. LinkedIn is heavily restricted. If APIs are gone/paywalled, use authorized exports, academic programs, RSS, or say it cannot be collected compliantly.

Sources: Reddit API https://www.reddit.com/dev/api/ ; YouTube Data API https://developers.google.com/youtube/v3 ; Mastodon API https://docs.joinmastodon.org/api/ ; Telegram Bot API https://core.telegram.org/bots/api

When to use: posts, metadata, timelines within documented limits. When it fails: ToS restriction, auth not granted, personal data risk.

Usage image: choose authorized source, collect raw, manifest it, then hand off.
