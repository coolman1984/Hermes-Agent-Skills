# Datasets and Files

For files/zips/PDFs/CSVs: download raw, checksum, record content-type, length, URL, license, and retrieval time. Do not parse during acquisition unless needed to discover links. Hand raw files to `data-extraction-mastery`.

When to use: public datasets, reports, bulk downloads, GitHub raw files. When it fails: large files, interrupted downloads, changing links. Watch: checksum drift and partial downloads.

Usage image: acquire only what is authorized, save raw + manifest, then hand off to extraction.
