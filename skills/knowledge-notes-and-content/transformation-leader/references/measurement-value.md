# Measurement and Value Realization

Baseline before; measure after. Use management currency: hours saved, close-days reduced, defects caught, error rate, cost avoidance, annual run-rate. Avoid vanity metrics: automations built, training attendance, demo count.

Value ledger is both program renewal case and leader advancement case.

Per initiative record: baseline, measured result, confidence, owner validation, annualized value, evidence link.

Use when: reporting value, business case, CEO/HQ update. Backfires when: value is claimed before measurement.
