# Improvement Loop

After every real meeting, rollout, or triage:
1. Update state files the same day.
2. Record stakeholder reactions in `state/stakeholders.md`.
3. Add decisions and commitments to `state/decision-log.md`.
4. Add new requests to `state/intake-log.md`.
5. Add measured value to `state/value-ledger.md`.
6. If prediction missed, log predicted → actual → why missed → prevention in `ERRORS.md`.
7. If a tactic worked repeatedly, patch the relevant playbook.

Quarterly: review value ledger as mandate renewal case and Mohamed’s advancement case.
