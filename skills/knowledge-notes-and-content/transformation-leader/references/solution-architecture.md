# Solution Architecture for Factory Automation

Workflow to solution chain: data sources → extraction → database → logic/agent → output/dashboard → human gate → adoption → handoff.

Factory realities: SAP/MES, OT/IT boundary, security ownership, production reliability, Arabic frontline use, buy-vs-build, pilot-then-scale. Avoid shiny objects that do not attack the true constraint.

Commission technical skills: research-collection for sources, data-extraction for files, database for modeling/reporting, engineering for apps/APIs, planning for rollout.

Use when: automation design begins. Backfires when: architecture is chosen before workflow/adoption is understood.
