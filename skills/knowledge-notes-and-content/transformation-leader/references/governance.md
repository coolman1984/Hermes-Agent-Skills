# Program and Portfolio Governance

Run as a portfolio with few active initiatives. Current team capacity default: 3 active initiatives max. Every request enters intake log with source, real need, triage outcome: now, sequenced, declined-with-reason.

Delivery standard: assess → build → validate with human accountability gate → document → train → hand off → measure.

CEO status must fit 60 seconds: green/yellow/red, outcome, risk, one ask.

Use when: request flood or portfolio status appears. Backfires when: governance becomes bureaucracy instead of focus protection.
