# Leader Operating System and Anti-Overwhelm

Anti-Overwhelm Protocol:
1. Brain-dump everything on the plate for five minutes.
2. Sort each item: this-week, sequenced, delegate, decline, renegotiate.
3. Extract the ONE move: highest leverage, usually CEO exposure or hard deadline.
4. Write weekly focus file.
5. Park everything else consciously with reasons.

Weekly rhythm: Sunday triage, meeting prep briefs, end-of-week state update and one-line retrospective.

Sustainability truths: renegotiate scope before silently drowning; finance day-job and transformation role compete for hours; rest is performance input.

Use when: user is overloaded or many requests appear. Backfires when: used as extra paperwork.
