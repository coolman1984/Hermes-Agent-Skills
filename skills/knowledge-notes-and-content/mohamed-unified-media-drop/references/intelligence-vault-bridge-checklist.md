# Intelligence Vault Bridge Checklist

Use this when a media note contains business, product, market, customer, automation, investing, workflow, strategy, or model/tool evaluation material.

## When to create a bridge note

Create or update an idea-vault note when the source yields at least one of:

- hidden customer pain
- buying trigger
- paying customer segment
- market wedge
- reusable workflow
- product or service idea
- connection to Mohamed's existing systems
- practical experiment toward customers, revenue, or decision quality

If the source is merely informational with no practical opportunity, skip the bridge and say why in the final note.

## Files to update

After writing the Downloads media note and the idea-vault extraction note, update these vault files when relevant:

- `00 - Index.md`: add the new card and update the count if the file tracks one.
- `02 - Categories.md`: add the card under the most fitting categories.
- `03 - Connections.md`: connect the card to existing idea chains.
- `04 - Stronger Combinations.md`: add only if the new idea meaningfully strengthens an existing combination.
- `05 - Review Queue.md`: classify as experiment, saved opportunity, parked, or current-week relevant.
- `06 - Media Source Map.md`: record source URL, Downloads note path, idea-vault note path, and reason for the link.

Do not force updates to every file if the link is weak. The source map is mandatory when a bridge note is created.

## Anti-distraction rule

If the idea is useful but not aligned with the current operating focus, save it as a radar or parked opportunity. Do not promote it into an active project.

For Mohamed's current pattern, a source about tools or models often belongs as:

- an enhancement to agent workflows
- an optional add-on to the active revenue experiment
- a future evaluation benchmark

not as a new standalone system.

## Verification

Before final delivery, verify:

- Downloads note exists and is non-empty.
- Idea-vault note exists and is non-empty when created.
- Source map contains both paths.
- The media note has all mandatory sections.
- The use-case count is exactly ten when the unified media-drop format is used.
- No unresolved placeholders remain.
- Arabic body lines do not contain embedded English words; ignore URL-only lines and standalone English title/source lines.

A small deterministic verification script is acceptable when multiple files are involved: check existence, sizes, required headings, source-map linkage, and mixed Arabic-English lines.
