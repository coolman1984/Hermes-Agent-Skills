# Agent Workflow Media Bridge

Use this reference when Mohamed sends a video, article, post, or repo about AI agents, loops, cron jobs, subagents, skills, prompts, memory, tool use, or agent operating systems.

## Core Classification

Default classification should be:

- attach to Mohamed's existing agent operating system
- improve Hermes skills, cron jobs, vault workflows, or verification habits
- do not create a new project unless the source has a clear customer, trigger, and test

For Mohamed, agent-workflow sources are usually system-strengthening material, not standalone novelty.

## Required Lens

When processing the media note, explicitly extract:

- what workflow pattern the source teaches
- what part is just tool-specific demonstration
- what must be true before automation is safe
- what human gate remains necessary
- what state is tracked across runs
- what verification proves the loop or agent worked
- what budget, permission, or rollback boundary is needed

## Mohamed Application Pattern

Tie the source to the live systems when relevant:

- Hermes skills
- cron jobs
- subagents
- Obsidian vault
- intelligence vault
- Egyptian stock workflow
- media-drop workflow
- company reporting or dashboard workflows

Do not merely say "this is useful for agents". Name the exact layer it strengthens.

## Anti-Premature-Autonomy Rule

For loop/agent sources, prefer this maturity ladder:

1. read-only observation
2. summarized recommendation
3. human-reviewed patch or note
4. limited internal write
5. external action only after explicit approval and safeguards

If the source is enthusiastic about self-prompting or background agents, add a serious caution about token cost, repeated errors, permissions, audit logs, state, and human gates.

## Idea-Vault Bridge Shape

When creating the idea-vault card, keep it compact and decision-oriented:

- why this matters now
- where it attaches to Mohamed's current system
- smallest safe experiment
- risks of turning it into a rabbit hole
- classification: attach to existing project, research more, or park

## Common Pitfall

Do not let a strong agent video turn into an endless research project or a new platform idea. The durable value is usually a small operating rule or loop pattern that strengthens an existing system.
