# YouTube Political-Economy / Power-Structure Bridge

Use when a YouTube source is not a product idea but teaches a durable lens for investing, markets, governance, regulation, media literacy, or institutional power.

## Pattern

Do not force a business idea or active project. Create the Downloads media note as usual, then create a compact intelligence-vault bridge as a **decision lens** when the source helps Mohamed evaluate risk or quality of judgment.

Good labels:

- عدسة قرار
- عدسة مخاطر سياسية
- معيار فحص استثماري
- معيار قراءة أخبار
- فرصة محفوظة كتحسين للنظام

Avoid labels that over-promote the source:

- مشروع جديد
- منتج مباشر
- تجربة أسبوعية
- خدمة قابلة للبيع

## Bridge note structure

Keep it short and action-oriented:

1. Source URL.
2. One-paragraph idea card.
3. The hidden risk or analytical blind spot the source reveals.
4. How Mohamed can apply it inside an existing system.
5. One small experiment or checklist.
6. Explicit classification: saved decision lens, not active project.
7. Reason for not turning it into a project now.
8. Link to the full Downloads media note.

## Vault updates

When relevant, update only the index files that reflect the real value:

- `00 - Index.md`: add the lens card.
- `02 - Categories.md`: usually under فرص سوقية واستثمارية or أنظمة ذكاء ومراقبة.
- `05 - Review Queue.md`: usually under فرص قوية محفوظة, not تجربة الأسبوع.
- `06 - Media Source Map.md`: mandatory if a bridge note was created.

Do not update stronger-combinations unless the source genuinely strengthens an existing execution path.

## Anti-distraction rule

For broad political-economy explainers, the default value is better judgment, not new work. The final note should explicitly say the source is being saved as a lens/checklist when that is the right classification.
