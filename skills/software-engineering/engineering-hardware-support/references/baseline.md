# Hardware Support Reference

Use for boot faults, crashes, overheating, disk/RAM/GPU issues, OS support.

Diagnostic chain: power → POST/beep/LED → BIOS/UEFI → storage visible → bootloader → OS logs → driver/app. For intermittent faults, check thermals, RAM, PSU, and storage SMART.

Template: `templates/hardware_diagnosis.md`.

Usage image: use when physical/device reality may be the cause.
