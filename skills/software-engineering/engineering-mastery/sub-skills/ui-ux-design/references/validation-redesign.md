# Weak Interface Redesign

Current: dense invoice dashboard with equal-weight headings, low contrast gray text, no empty/error state, tiny click targets.

Redesign:
- Hierarchy: one primary KPI row, secondary details below.
- Contrast: WCAG-readable text/background contrast.
- Proximity: filters grouped together, actions near affected table.
- Feedback: loading, empty, error, and success states.
- Error prevention: disabled export until validation passes.
- Accessibility: keyboard focus and labels for filters.
