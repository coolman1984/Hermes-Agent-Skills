# Frontend Reference

Use for React/Next components, dashboard tables, charts, forms, and state.

Top traps: div soup, no labels, no error state, hydration assumptions, stale state, global store for local state, unbounded rerenders, inaccessible tables, ignoring mobile widths, hardcoded text without localization.

Runnable example is in `scripts/render_component_check.py`.

Usage image: use when a human must interact with data safely.
