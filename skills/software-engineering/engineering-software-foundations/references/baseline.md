# Foundations Reference

Use when changing code structure, tests, algorithms, or Git history.

Top traps: premature abstraction, fake DRY, hidden side effects, no regression test, rewriting while debugging, bad names, comments explaining unclear code instead of improving code, clever algorithms on tiny data, merge conflict panic, rebasing shared branches without coordination.

Runnable example is in `scripts/refactor_example.py`.

Usage image: use when code must become safer and easier to change.
