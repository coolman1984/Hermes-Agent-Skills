# نظام متابعة المحفظة المصرية

## Summary

هذه الصفحة تجمع النظام التشغيلي للمحفظة المصرية المركزة لكن المنضبطة: نواة قليلة، تكتيك محدود، نقد عند الحاجة، نشاط شرعي مقبول، ومراجعة يومية وأسبوعية وشهرية تحول الحقائق الرسمية إلى قرارات مختصرة. التنفيذ النهائي يبقى بشريًا، لكن الويكي يفرض الانضباط والوضوح.

## Core Claims

- ركز أكثر وشتت أقل، ولا تحتفظ بمراكز ديكورية.
- المحفظة تجمع نواة قليلة مع طبقة تكتيكية محدودة ونقد مسموح عند غياب الفرص.
- لكل مركز دور واضح داخل المحفظة، لا مجرد وجود شكلي.
- الحقيقة الرسمية أولًا عبر EGX وCBE وCAPMAS وFRA والمنظم القطاعي.
- اليومي والأسبوعي والشهري يصنعون القرار بدل الضوضاء اللحظية.
- التنفيذ النهائي ما زال بشريًا وليس آليًا بالكامل.
