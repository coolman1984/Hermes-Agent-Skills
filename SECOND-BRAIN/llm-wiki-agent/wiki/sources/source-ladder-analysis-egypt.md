# سلم مصادر التحليل اليومي والساعة

## Summary

هذا السلم يرتب مصادر التحليل في ثلاث طبقات: الحقيقة الرسمية أولًا، ثم الفهم والتفسير، ثم المتابعة والتوقيت. EGX وCBE وCAPMAS وFRA في القمة، ثم IMF وPMI وWorld Bank Commodities وEFG Hermes، ثم Reuters وTradingView وInvesting للمتابعة السريعة.

## Key Claims

- لا نبدأ من رأي السوق، بل من الحقيقة الرسمية ثم الفهم ثم المتابعة ثم التوقيت.
- المصدر الواحد لا يكفي، وأداة المتابعة لا تبني الفرضية من الصفر.
- إذا تعارضت مصادر المتابعة مع الإفصاح أو القوائم أو المنظم، يقدم الرسمي.
- Camoufox يستخدم للنص فقط داخل هذا المسار، لا كخيار بصري افتراضي.
- الطبقة الرسمية تشمل EGX وCBE وCAPMAS وFRA والمنظم القطاعي لكل نشاط.
- الطبقة التفسيرية تشمل IMF وPMI وWorld Bank Commodities وEFG Hermes Research.

## Key Quotes

> "لا نبدأ من رأي السوق. نبدأ من الحقيقة الرسمية، ثم الفهم والتفسير، ثم المتابعة، ثم التوقيت."
> "إذا ظهرت صفحة فارغة نصيًا، ننتقل إلى صفحة نصية بديلة أو PDF مباشر قبل أي وسيلة بصرية."
