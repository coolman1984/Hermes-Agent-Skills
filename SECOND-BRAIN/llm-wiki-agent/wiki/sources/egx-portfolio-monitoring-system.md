# EGX Portfolio Monitoring System

## Summary

هذا هو دليل التشغيل للمحفظة المصرية المركزة لكن المنضبطة. يعرّف فلتر النشاط المقبول شرعياً، وشكل المحفظة المستهدف، وطبقات المصادر المعتمدة، وقاعدة Camoufox للروابط الصعبة، ودورة المتابعة اليومية والأسبوعية والشهرية، والمخرجات القياسية لكل سهم.

## Key Claims

- ركز أكثر وشتت أقل، ولا تحتفظ بمراكز ديكورية.
- المحفظة المستهدفة تجمع نواة قليلة مع طبقة تكتيكية محدودة ونقد مسموح عند غياب الفرص.
- الفائدة والسيولة والتشغيل والدفاع والتصدير والعقار الانتقائي تمثل أدوارًا مختلفة داخل المحفظة.
- الحقيقة الرسمية أولًا: EGX وIR الشركة وCBE وCAPMAS وFRA والمنظم القطاعي.
- Camoufox-first للروابط الصعبة مثل X وSubstack، مع أولوية للنص لا للصور.
- اليومي والأسبوعي والشهري يحددان ماذا نحتفظ وماذا نقلل وماذا نخرج.

## Key Quotes

> "لا نبدأ من السعر، بل من الدور والجودة والمرحلة"
> "الرسمي يغلب غيره دائمًا"
