# الهيئة العامة للرقابة المالية

## Summary

الهيئة العامة للرقابة المالية هي المرجع الرسمي للتنظيم والقواعد ومهل الإفصاح وتغير شروط اللعبة. في هذا الويكي تعد مخاطرة مستقلة وليست مجرد ضوضاء، خصوصًا في القطاعات المنظمة.

## Role in the system

- تحكم القواعد والمهل والإفصاح في القطاعات المنظمة.
- تخبرنا متى تغيرت شروط اللعبة وليس فقط الأسعار.
- ضرورية عند تقييم البنوك والاتصالات وبعض الأنشطة المنظمة الأخرى.
- يجب الرجوع إليها كلما ظهرت خطوة قد تغير الامتثال أو التسعير أو الترخيص.
