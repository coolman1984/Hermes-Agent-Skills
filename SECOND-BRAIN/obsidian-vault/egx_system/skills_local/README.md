# skills_local

هذا المجلد مخصص للمهارات المحلية التي تخدم نظام إدارة المحفظة المصرية.

## الهدف
تثبيت طريقة عمل واحدة بحيث يستطيع أي AI يأتي لاحقًا أن يدير النظام بنفس المنطق، لا باجتهاد متغير كل مرة.

## المهارات العاملة حاليًا عبر market profile
- `egx-daily-cycle`
  - يقرأ الملفات المحلية
  - يصدر تقريرًا يوميًا + JSON
  - يفشل بصراحة عند أي parsing issue

- `egx-decision-gate`
  - يقرأ التقرير اليومي وملف JSON
  - يطابقهما مع القواعد والدستور
  - يصدر مذكرة قرار محلية مختصرة

## ما يجب أن تعرفه أي مهارة محلية مستقبلية
1. تبدأ من القواعد والدستور لا من السعر
2. تستخدم المصدر الرسمي أولًا
3. عند صعوبة المصدر النصي: Camoufox مباشرة
4. تلتزم بفلتر النشاط المقبول شرعياً
5. تخدم هدف: نمو سريع بمخاطرة محسوبة
6. لا تصدر أوامر تنفيذ تلقائي

## مهارات منطقية لاحقًا
- مهارة تحديث التصنيفات داخل `positions.csv`
- مهارة مراجعة أسبوعية قطاعية
- مهارة خريطة شهرية للمحفظة
- مهارة مقارنة اسمين داخل نفس الوظيفة
- مهارة رصد التركز والتكرار تلقائيًا
