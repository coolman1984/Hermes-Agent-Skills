# LLM Knowledge Base — خطة عملية

مرجع مرتبط: [[CURRENT-SNAPSHOT]]

## الهدف
بناء ويكي حي للمعرفة: مصادر خام ثابتة + طبقة wiki مولّدة بالـ LLM + قواعد تشغيل واضحة + مراجعة دورية + أتمتة تدريجية.

## المبدأ الحاكم
- السياق أولًا
- القواعد ثم الذاكرة ثم التحقق ثم الأتمتة
- المصدر الخام لا يُعدّل
- التناقضات تُسجَّل ولا تُخفى
- كل مخرجات مهمة تُعاد إلى قاعدة المعرفة

## المرحلة 0 — تحديد النطاق
- اختر مجالًا واحدًا فقط للبداية
- حدّد 20–50 مصدرًا عالي الجودة
- عرّف ماذا يعني النجاح: بحث أسرع، تلخيص أدق، روابط أفضل، وتراكم معرفي واضح

## المرحلة 1 — هيكل الملفات
- raw/ للمصادر الثابتة
- wiki/ لصفحات المعرفة المولّدة
- schema/ لقواعد التشغيل والقوالب
- outputs/ للمخرجات: ملاحظات، تقارير، شرائح، رسوم

## المرحلة 2 — القوالب الأساسية
أنشئ 4 أنواع صفحات فقط في البداية:
- Source Note: ملخص المصدر وروابطه
- Entity Page: أشخاص، أدوات، مشاريع، مفاهيم
- Concept Page: الفكرة نفسها وما يرتبط بها
- Overview Page: الخلاصة العليا وخرائط الربط

## المرحلة 3 — دورة الإدخال
لكل مصدر جديد:
1. قراءة المصدر
2. استخراج النقاط المهمة
3. إنشاء/تحديث Source Note
4. ربطه بصفحات الكيانات والمفاهيم
5. تحديث الـ Overview إن تغيّر شيء مهم
6. تسجيل أي تعارض أو نقص أو افتراض

## المرحلة 4 — الحوكمة والجودة
- فحص التناقضات
- فحص الصفحات اليتيمة أو غير المرتبطة
- فحص المصادر المفقودة أو غير المؤرخة
- فحص الادعاءات التي تحتاج تحققًا خارجيًا
- مراجعة أسبوعية قصيرة لتصفية الضوضاء

## المرحلة 5 — المخرجات
المخرجات لا تبقى في الشات فقط، بل تعود للنظام:
- تقارير Markdown
- قوائم عمل
- ملخصات بحثية
- شرائح Marp عند الحاجة
- رسوم/صور إذا كانت تساعد الفهم

## المرحلة 6 — الأتمتة
بعد ثبات الأساس:
- أمر CLI واحد للإدخال
- أمر CLI واحد للمراجعة
- أمر CLI واحد للتنظيف
- كرون أسبوعي للمراجعة
- كرون اختياري لاستخراج المصادر الجديدة

## تعريف النجاح
أعتبر المشروع ناجحًا عندما:
- أضيف مصدرًا جديدًا فيتحول تلقائيًا إلى معرفة مترابطة
- أستطيع سؤال النظام سؤالًا معقدًا فيرجع بإجابة مبنية على الويكي كله
- تقلّ الحاجة للتفكير اليدوي في التنظيم والربط
- تبقى المعرفة قابلة للمراجعة والتوسّع بدون فوضى

## الحالة الحالية
- تم إدخال أول دفعة من مصادر EGX في الويكي المحلي، مع صفحات مصادر وكيانات ومفاهيم وربطها بالجراف.
- أصبحت القاعدة العملية واضحة: الدستور -> سلم المصادر -> الروتين -> القطاعات.

## الخطوة التالية
اختيار الدفعة الثانية من الحالات القطاعية أو التقارير التشغيلية وإدخالها كمصادر جديدة.
