## ٢. أنماط أسراب الوكلاء

| المصدر | النمط | التفاصيل |
|--------|-------|----------|
| **Anthropic Multi-Agent Research** | Orchestrator-Worker | وكيل قائد يخطط، 3-5 وكلاء متوازيين، وكيل تركيب. تحسن 90.2%. |
| **Kimi K2.6** | Agent Swarm | 50-300 وكيل من أمر واحد. Document-to-Skill. نموذج مفتوح المصدر. |
| **Swarms (kyegomez)** | متعدد الأنماط | هرمي، متسلسل، متوازي، خليط وكلاء. MCP integration. |
| **Paper Circle** | Knowledge Graph | خط أنابيب اكتشاف + تحليل → رسم معرفي بأنواع عقد. |
| **CrewAI** | Role-based | أدوار محددة: باحث، محلل، كاتب، مراجع. |
| **LangGraph** | Graph workflow | تنسيق قائم على الرسم البياني. Stateful، checkpoint-enabled. |
| **GraphAgents** | Graph-guided | رسم معرفي يوجه الوكلاء للاكتشاف عبر المجالات. |

**النمط المختار:** Anthropic Orchestrator-Worker (المعيار الذهبي حاليًا).
**نموذج التكلفة:** "خطط بـ Opus، نفذ بـ Kimi" — وفر ~80%.

## ٣. نقل الأسلوب (Document to Skill)

| المصدر | المنهجية |
|--------|----------|
| **Kimi K2.6** | يحول وثيقة واحدة إلى مهارة قابلة لإعادة الاستخدام — يلتقط التنسيق والنبرة والهيكل. |
| **Anthropic Agent Skills** | مهارات رسمية لـ Claude: تعليمات + كود + مراجع في مجلد. |
| **Claude Skills: Voice DNA** | استخراج "بصمة الصوت"، أنماط الجمهور، سياق العمل. |
| **Tiago Forte** | اختيار عينات كتابة → دليل أسلوب → دليل تنفيذ → حلقة تغذية راجعة. |
| **George Vetticaden** | ترميز "الحمض النووي الإبداعي" في تعليمات الوكيل. |

**منهجية Compound:** 5 خطوات (استخراج عينات → بصمة أسلوب → Claude Skill → تطبيق → تغذية راجعة).

## ٤. أنظمة تراكم المعرفة

| المصدر | المفهوم |
|--------|---------|
| **Leverage Loops (Brandon Galang)** | "النظام الذي حوّل خبرتي المبعثرة إلى ميزة تنافسية متراكمة." |
| **Compound Loop (Mario Thomas)** | إطار "حلقات التراكم" — تخصصات AI متعددة تتفاعل تآزريًا. |
| **Cypris** | "طبقة ذكاء متراكمة" للمؤسسات — 500M+ براءة اختراع وورقة بحثية. |

**الفجوة:** لا يوجد منتج يسمي نفسه "Compounding Knowledge Vault". **فرصة تموضع فريدة.**
